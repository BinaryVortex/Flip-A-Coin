# Flip-A-Coin

A simple and fun coin flip game built with HTML, CSS, and JavaScript. Test your luck by flipping a virtual coin and keep track of your heads and tails results!

## 🚀 Live Demo

Play the game online: [Flip-A-Coin](https://binaryvortex.github.io/Flip-A-Coin/)

## ✨ Features

- **Coin Flip Animation**: Realistic flipping animation with heads and tails sides.
- **Result Tracking**: Displays the count of heads and tails flips.
- **Reset Functionality**: Reset the counters to start fresh.
- **Responsive Design**: Works on various screen sizes.

## 🎮 How to Play

1. Click the "Flip Coin" button to flip the virtual coin.
2. Watch the animation as the coin flips.
3. Check the results in the heads and tails counters.
4. Use "Reset" to clear the counters and start over.

## 🛠️ Technologies Used

- **HTML**: Structure of the game interface.
- **CSS**: Styling and animations for the coin flip.
- **JavaScript**: Logic for flipping, tracking results, and interactions.

## 🚀 Getting Started

To run this game locally:

1. Clone the repository:
   ```
   git clone https://github.com/BinaryVortex/Flip-A-Coin.git
   ```
2. Navigate to the project directory:
   ```
   cd Flip-A-Coin
   ```
3. Open `index.html` in your web browser.

That's it! The game will load and you can start flipping coins.
